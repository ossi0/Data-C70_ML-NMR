## Training process of NequIP model

The training process of a NequIP model is briefly described here.

### Input files

Training of a NequIP model requires the input file `config.yaml` to specify the hyperparameters, and the dataset file `molecules.db`.

```
./
  config.yaml      # Hyperparameters and the training protocol are specified here
  molecules.db     # The dataset
  run.job          # The script to start the training on Puhti supercomputer or similar HPC
```

The internal hyperparameters of the model and the training process are controlled through the `config.yaml` input file.

### Starting the training

With NequIP and PyTorch 2.2+ installed (with Python 3.10+), and a CUDA-compatible GPU available, the training process of NequIP model may be started simply with the command
```nequip-train -cn config.yaml```

Performing the training on a HPC can be started by running the script

```bash
sbatch run.job
```


### Output files

The training process creates the following output files:
```
./
  ml_nequip-output_<JOB-ID>.txt     # Output log file of the training
  ml_nequip-errors_<JOB-ID>.txt    # Error log file of the training
  outputs       # A directory containing data from the training process, including the final model file
```

### Compiling the model

Compiling the trained NequIP model from the generated .ckpt file is performed by running the following compiling Python script:

```bash
sbatch compile.sh
```
# Note that the path to the .ckpt (found in the `./outputs` directory generated by the training process) file must be set to point to the corresponding file



- In the [output_files](./output_files) directory, the output files of the training process of the NequIP MLIP model is provided.
- The trained NequIP model parameter file can be found in the corresponding subdirectory of the `output_files` directory, or in the external [Fairdata repository](https://doi.org/10.23729/fd-c64c043e-473e-371d-9586-8fd3d04e2fb0).
- The dataset file molecules.db is not included in this repository due to its size, but it can be found from the external [Fairdata repository](https://doi.org/10.23729/fd-c64c043e-473e-371d-9586-8fd3d04e2fb0).
